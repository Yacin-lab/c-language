# Arrays & Strings (C)

Small C programs to practice **arrays, searching, sorting, and matrices**.
These exercises focus on basic algorithmic thinking and problem solving.

## Structure

```
arrays-strings/
│
├── one-dimensional
│   ├── array_stats.c
│   ├── reverse_array.c
│   └── remove_duplicates.c
│
├── search
│   ├── linear_search.c
│   └── binary_search.c
│
├── sort
│   ├── bubble_sort.c
│   ├── selection_sort.c
│   └── sort_comparison.c
│
└── two-dimensional
    ├── matrix_addition.c
    ├── matrix_transpose.c
    └── matrix_max.c
```

## Topics Practiced

* One-dimensional arrays
* Searching algorithms
* Sorting algorithms
* Two-dimensional arrays (matrices)

## Compile Example

```
gcc file.c -o program
./program
```
