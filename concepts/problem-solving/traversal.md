# Traversal

## Idea
Move through data step by step.

## Used In
- strings
- arrays
- linked lists
- matrices

## Basic Form
```c
int i = 0;

while (str[i])
{
    i++;
}
```

## Important Concepts
- index movement
- boundaries
- stopping conditions
- forward/backward traversal

## Common Mistakes
- infinite loops
- off-by-one
- accessing invalid memory
