# Pointers & Dereference (C)

Small C programs to understand **pointers and dereferencing**.

## Files

* `pointer_basic.c` → basic pointer usage
* `swap_using_pointers.c` → swap two variables using pointers
* `array_with_pointers.c` → access array elements using pointers
* `string_length_pointer.c` → compute string length using pointer traversal

## Concepts

* memory addresses
* `&` address operator
* `*` dereference operator
* pointers with arrays
* pointers with functions

## Compile

```
gcc file.c -o program
./program
```
