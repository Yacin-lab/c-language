# Structures & Unions (C)

Mini programs to understand **structs and unions** in C.

## Files

* struct_basic.c → basic struct
* struct_array.c → array of structs
* struct_function.c → struct with functions
* union_basic.c → basic union usage
* struct_vs_union.c → difference between struct and union

## Concepts

* grouping data with struct
* accessing fields (`.`)
* passing structs to functions
* memory sharing in union
* difference: struct vs union

## Compile

```
gcc file.c -o program
./program
```
